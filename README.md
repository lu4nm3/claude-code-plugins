# claude-code-plugins

A collection of Claude Code plugins.

| plugin | skills |
|---|---|
| [lightroom-classic](lightroom-classic) | `cull-raw-photos`: groups a folder of Canon CR3 raws into moments, picks the best frame of each, and writes Green/Yellow color labels to XMP sidecars that Lightroom Classic reads |

## Install

```
/plugin marketplace add /path/to/claude-code-plugins
/plugin install lightroom-classic@luis-plugins
```
